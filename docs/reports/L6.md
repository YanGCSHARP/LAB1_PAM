# Отчёт по лабораторной работе L6

**Дисциплина:** Программирование мобильных приложений (PAM), UTM / FCIM / ISA
**Тема:** T7 — WalletMate (личные финансы), уровень сложности «повышенный»
**Автор:** Yang Alexandru, группа `TI-236`
**Этап:** L6 — персистентность и офлайн-кэш, тесты, release-сборка, защита
**Дата:** ноябрь 2026

---

## 1. Цель этапа

Довести приложение до сдачи: данные должны открываться без сети, сборка —
подписываться и обфусцироваться, а проект — быть готовым к защите.

## 2. Офлайн-копия данных

- `core/data/cache/data_cache.dart` — `DataCache` в `shared_preferences`
  (в памяти — с mock-бэкендом и в тестах) и `CachedCollection<T>`: загрузка
  через сеть с сохранением копии, при `NetworkException` — ответ из копии.
- `core/data/cache/cached_repositories.dart` — обёртки над четырьмя
  REST-репозиториями. Успешные изменения сразу попадают в копию.
- `offlineProvider` — показывает в `HomeShell` плашку «Нет соединения. Показаны
  сохранённые данные, изменения недоступны.»
- Изменения без сети не принимаются: пользователь видит ошибку, а не
  «сохранено», которое потом потеряется.
- Выход из аккаунта и вход другим пользователем стирают копию.

Токен сохранялся с L5, поэтому без сервера приложение открывается сразу на
панели с сохранёнными данными.

## 3. Release-сборка

| Что | Как |
|---|---|
| Имя | WalletMate на Android, iOS и web |
| Подпись | `android/key.properties` (не в git, образец `key.properties.example`); без него — отладочный ключ |
| Обфускация | `--obfuscate --split-debug-info=build/symbols` |
| Размер | 53 МБ на все ABI, `--split-per-abi` — по одному файлу на архитектуру |
| Backend | `dotnet publish -c Release`, секрет `JWT_SECRET` задаётся переменной |
| Сборка на Windows | `kotlin.incremental=false`: проект на D:, кэш пакетов на C: — инкрементальные кэши Kotlin ломали release |

## 6. Отличия от плана L1

| План L1 | Сделано | Почему |
|---|---|---|
| ASP.NET Core + EF Core, ProblemDetails | шаблон курса: Minimal API, SQLite, формат ошибок шаблона | требование L5 |
| `drift` и очередь офлайн-изменений | копия данных на чтение в `shared_preferences` | без очереди нет конфликтов синхронизации; главный сценарий — посмотреть данные без связи |
| `/dashboard/summary` на сервере | агрегаты считает клиент, сервер отдаёт `balance` и `spentAmount` | один расчёт для mock и сервера |
| CI GitHub Actions | не сделано | вне обязательных требований |
